# Bundled typefaces

- BitterBold.ttf: static weight-700 instance of the original Google Fonts Bitter variable font, created with fontTools.varLib.instancer. Source: https://github.com/google/fonts/tree/main/ofl/bitter.
- AtkinsonRegular.ttf and AtkinsonBold.ttf: unmodified regular/bold files from https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible.
- SIL Open Font License texts are bundled alongside the files.

All fonts are local app assets; opening the app does not fetch fonts from a third-party service. The aliases in src/components/theme.ts and src/app/_layout.tsx map explicitly to these files.
